version.dll is built from version.c, version.def, version.rc and patch.h with Zig 0.14.1
(https://ziglang.org, a single archive, nothing to install):

zig cc -target x86_64-windows-gnu -shared -O2 -s -o version.dll version.c version.def version.rc

Any MinGW-w64 GCC or Clang targeting x86_64 Windows works too.

version.def: the 17 functions of the Windows version.dll, each passed on to the real one from
System32 (the game uses three of them).

patch.h: IMAGE_SIZE = the size of the Yakuza3.exe image in memory; regions = the places changed
in the game code, by code address (RVA), with the original bytes that must be found there and
the new bytes. If the image size or any original byte differs, nothing is changed.
